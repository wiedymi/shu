# Security Policy

## Supported versions

Security fixes are made on the latest released version of Shu.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected security problem.

When GitHub's private vulnerability reporting is available for this repository,
use the **Report a vulnerability** button in the repository's Security tab.
Otherwise, contact [contact@wiedymi.com](mailto:contact@wiedymi.com) with:

- a concise description of the issue;
- steps to reproduce it;
- the affected Shu version and platform;
- any suggested mitigation, if you have one.

Do not include passwords, access tokens, private repository URLs, or other
unnecessary sensitive data. You will receive an acknowledgement as soon as
practical, followed by updates while the issue is assessed and fixed.
